# GitHub Notify for Windows and Linux

This directory preserves the original Go app for Windows and Linux. macOS development uses the Swift app at the repository root. The Go code has no macOS build target.

The tray menus, GitHub API client, repository filters, and Chrome-based settings UI retain their original behavior. The tray dependency now uses Ayatana AppIndicator on Linux, which is available on current Debian and Ubuntu releases.

## Prerequisites

- Go 1.27 is the tested toolchain and Docker/CI version.
- Chrome or Chromium for the settings window. Without it, settings open in a text editor as before.
- On Linux, GCC, GTK 3, and Ayatana AppIndicator development libraries:

```sh
sudo apt-get install gcc libgtk-3-dev libayatana-appindicator3-dev
```

Your Linux desktop also needs a tray host or AppIndicator extension. Windows builds do not require CGO.

## Build

Run from this directory:

```sh
make build-win              # bin/windows/github-notify.exe, amd64
make build-linux            # bin/linux/github-notify, amd64, build on Linux
make arch=arm64 build-linux # Build on an ARM64 Linux machine
make test                   # Run on Windows or Linux
make install                # Build and install/update for the current Windows/Linux host
```

Windows builds can be cross-compiled from macOS or Linux. Linux uses CGO and needs a native Linux toolchain or a suitable cross-compiler. From macOS, Docker provides that environment:

`make install` uses `go install`, targeting the current host architecture. It writes to `GOBIN`, or to the Go toolchain's default `GOPATH/bin` directory. Set `GOBIN` to an absolute path to choose another destination. Quit a running legacy app before updating it. The root `make install` delegates here on Windows and Linux.

```sh
make bundle-linux            # amd64 container, emulated on Apple Silicon
make arch=arm64 bundle-linux # Native ARM64 Linux container
```

Run the resulting executable directly. Configure a GitHub token with the `notifications` scope through the tray's Settings item. Legacy token storage and autostart behavior remain unchanged.

## Shared assets

The original screenshots and app icon remain in `../assets/`. Tray PNG and ICO originals are in `../assets/tray/`. The native macOS bundle copies the PNG files, while Go embeds the generated byte arrays in `icon/`.

After changing tray artwork, run `make generate` from this directory. It regenerates the Go arrays from those shared files and installs `2goarray` if needed. Normal builds do not need this tool or a copy of the source assets.
